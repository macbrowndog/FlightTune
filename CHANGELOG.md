# Changelog

Notable changes to FlightTune are recorded here.

## 2.0.0 - 2026-08-17

### Added

- Explicit consent and minimized-data disclosure for optional OpenAI review.
- Allowlisted AI configuration changes with per-setting numeric ranges.
- Visible OpenAI error and local-fallback reporting.
- Electron CSP, navigation allowlisting, webview blocking, and denied permissions.
- Data-driven CPU tiers and automated optimizer, privacy, hardware, backup, and rollback tests.
- Windows CI and certificate-gated signed release workflows.
- MIT license, security policy, and contribution guidance.

### Changed

- Optional structured AI review now uses the cost-sensitive GPT-5.6 Luna model.
- The estimated FPS label is now described as a profile target.

## 1.1.1

- Initial FlightTune Windows release candidate with hardware detection, VR VFR/IFR recommendations, manual profile snapshots, and optional OpenAI review.
